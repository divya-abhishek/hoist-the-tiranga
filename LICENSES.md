# Licenses & attribution

## India map data
`assets/india-map.js` contains the India map path data used by this project.

- **Source:** [`@svg-maps/india`](https://github.com/VictorCazanave/svg-maps/tree/master/packages/india) v2.0.0
- **Author:** Victor Cazanave
- **License:** [Creative Commons Attribution 4.0 International (CC-BY-4.0)](https://creativecommons.org/licenses/by/4.0/)

The map is used under CC-BY-4.0, which requires attribution. This file, plus the
credit line in the README, satisfies that requirement. The geometry was **not**
generated by AI — it is a real, published vector map of India with state and
union-territory boundaries. It was converted from the package's ES module into a
plain browser global (`window.INDIA_MAP`) without altering the coordinates.

> Map of India © Victor Cazanave, licensed under CC-BY-4.0. Boundaries are
> approximate and shown for symbolic, decorative purposes only; they are not an
> authoritative depiction of any border.

## Fonts
The repaired site uses only device-provided system fonts and Georgia/Times
fallbacks. It does not load a font or icon font from a third-party CDN.

## Artwork
The decorative images in `assets/` (`hero-*.webp`, `success-burst.png`,
`map-atmosphere.png`, `share-card-bg.png`, `empty-map-glow.png`,
`hoisted-glow.png`) were supplied by the project owner. The Tiranga (Indian
national flag) shown on markers is drawn programmatically in code
(`lib/tiranga.js`) — no AI image of the flag is used.

## This project's code
All HTML, CSS and JavaScript in this repository (excluding the map data and
fonts above) may be reused freely for your own Independence Day project.
